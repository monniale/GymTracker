## Context
Round 1 (docs/FEATURE_PLAN.md, nine features) is built; PR #13 (AI meal estimate, `feat/11-meal-estimate`) is the last one still open. The owner now asks for the next feature round, aimed at making GymTracker the best open-source gym app. "Best" has two axes that the current repo covers unevenly:

1. **Product depth** vs. Hevy / Strong / Liftosaur / Boostcamp / RP: programs with progression schemes, RPE, set types, imperial units, light theme, measurements, Health Connect.
2. **Open-source excellence**: the repo is public but has **no LICENSE** (so legally it is not open source yet), no GitHub Release, no CI on pull requests, no CONTRIBUTING, no issue templates, GitHub-only sync and Gemini-only AI.

Outcome of this plan: a prioritised, owner-approved set of features with file-level design, build order and verification, written to `docs/FEATURE_PLAN.md` (replacing the round-1 content, which moves to a short "Done" section), then built one stacked PR per feature as decided in round 1.
